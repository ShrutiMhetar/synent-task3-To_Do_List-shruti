#To-Do List

▪ Description:-

This is a Python-based To-Do List application developed as part of the Synent Technologies Python Development Internship.

The application allows users to add, view, and delete tasks through a simple menu-driven interface.

✦ Features:-

- Add new tasks
- View all tasks
- Delete tasks
- Task count display
- Empty task validation
- Invalid task number handling
- Invalid menu choice handling
- Simple command-line interface

◆ Technology Used:-

- Python
- Lists
- Functions
- Exception handling

➤ How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

    To_do_list.py

4. Select an option from the menu.
5. Add, view, or delete tasks as required.

★ Objective:-

To develop a simple Python-based To-Do List application that allows users to manage tasks while practicing lists, functions, loops, conditional statements, and exception handling.
